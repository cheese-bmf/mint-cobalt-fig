Link card fixtures

링크 카드(OG·커스텀 메타 태그) 수동 검증용 테스트 페이지 모음. 테스트 픽스처이며 실제 서비스 페이지가 아니다.

사용법: URL 을 복사해 글쓰기 본문에 붙이면 링크 카드가 뜬다. 커스텀 카드(gaap:*)는 그 태그를 신뢰하는 환경에서만 MOD 로 나온다. 링크 카드는 서버 캐시가 있어 페이지를 고친 뒤 다시 볼 때는 ?v=2 처럼 쿼리를 바꾼다.

케이스내용글쓰기 화면 기대
A. OG
og-basic
기본		og:title·description·image 가 모두 있는 일반 카드파란 이미지 + 제목·설명·도메인 카드
og-title-fallback
title 대체		og:title 이 없으면 문서 <title> 로 제목을 채운다제목 「Fixture · title 태그 대체」, 이미지 대신 사이트 아이콘
og-no-title
title null = 실패		og:title 도 <title> 도 없으면 code 0 이어도 title null도메인·URL 카드 + 「미리보기 없음」
og-blank-title
R13-blank		공백뿐인 og:title 과 제로폭 문자뿐인 <title> 은 빈 문자열이 아니라 null도메인·URL 카드 + 「미리보기 없음」
og-image-relative
R11-relative		앞뒤 공백이 있는 상대 og:image 는 최종 URL 기준 절대 URL 로초록 이미지 카드
og-image-base
R11-base		<base href> 가 있으면 상대 og:image 를 그 기준으로 해석주황 이미지 카드
og-image-unsafe
R11 스킴		http(s) 가 아닌 og:image(javascript:)는 null이미지 없이 사이트 아이콘 카드
favicon-compact
favicon 순서		og:image 가 없으면 축약형 — apple-touch-icon 을 일반 icon 보다 먼저 고른다이미지 없이 보라 아이콘 카드
favicon-svg-only
SVG 아이콘 제외		SVG 아이콘만 있으면 고르지 않고 사이트 루트 /favicon.ico 로 대체(존재 확인 없음)기본 아이콘 카드(루트 favicon 은 404 라 기본 아이콘으로 대체)
text-sanitize
R13-strip		개행은 공백 하나, U+202E·U+200B·태그 문자 제거, ZWJ 시퀀스는 유지제목 「줄 바꿈 뒤집기제로폭 👨‍👩‍👧 🏴」
text-cut
R13-cut		title 300·description 1000 코드 포인트 상한 — 경계의 ZWJ 시퀀스는 쪼개지 않고 통째로 버린다아주 긴 제목·설명(말줄임 없이 잘림)
meta-refresh
R9 meta refresh 미추적		<meta http-equiv=refresh> 는 따라가지 않는다 — 이 페이지 자신의 og 로 카드제목 「Fixture · meta refresh 원본」(기본 OG 카드가 아님)
body-cap
R10 본문 1MB 상한		<head> 안 1.1MB 패딩 뒤에 og 태그 — 상한에서 읽기를 멈추므로 og 를 못 읽는다도메인·URL 카드 + 「미리보기 없음」(제목을 못 읽음)
locale-ko
R16 선언 언어		og:locale=ko_KR 선언 페이지 — X-Lang en 으로 불러도(맞는 슬롯 없음) 어긋난 슬롯을 내린다X-Lang ko·en 어느 쪽이든 같은 한국어 제목
B. 커스텀
gaap-game-full
R14-game		game 카드 전 필드 — 공식 뱃지·평점·플레이 수빨간 게임 이미지 + 제목 「랩 게임」
gaap-game-minimal
R14 필수만		card_type·game_id 만 — 선택 필드 키는 생략, is_official=falseog 제목·파란 이미지 카드(모드 제목 없음)
gaap-channel-full
R14 channel		channel 카드 — 프로필 이미지·팔로워 수·게임 수제목 「랩 채널」(채널 프로필 이미지 대신 og 이미지가 보일 수 있음)
gaap-play-together
R14 play_together		함께하기 카드 — game_id + room_id빨간 이미지 + 제목 「같이 하실 분」
gaap-play-missing-room
R14-reject		play_together 인데 room_id 없음 → EXTERNAL일반 카드(파란 이미지)
gaap-unknown-type
R14-reject		모르는 card_type(video) → EXTERNAL일반 카드(파란 이미지)
gaap-invalid-id
R14-reject		game_id 형식 위반(공백·특수문자 — ^[A-Za-z0-9_-]{1,64}$) → EXTERNAL일반 카드(파란 이미지)
gaap-optional-invalid
R14-optional		rating 101·play_count "1.2만" 은 그 필드만 빠지고 카드 유지, badge "Official"(대문자)은 공식 아님제목 「선택 필드 위반 게임」
gaap-name-attr
R14 property·name		gaap:* 를 property 대신 name 속성으로 선언해도 읽는다제목 「name 속성 게임」
gaap-title-cut
R14 gaap:title 100		gaap:title 은 R13 정화 + 100 코드 포인트로 절삭「라」 100자 제목
gaap-image-unsafe
R14·R11		gaap:image 가 javascript: 면 mod.image_url 생략(카드는 유지)og 파란 이미지 + 제목 「이미지 거른 게임」
gaap-image-base
R14-game <base href>		상대 gaap:image 는 <base href> 기준 절대 URL빨간 게임 이미지
gaap-badge-trim
R14 badge		badge 는 앞뒤 공백을 지운 값이 정확히 official 일 때 공식og 제목·파란 이미지 카드
